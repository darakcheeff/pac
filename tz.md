# Техническое Задание (ТЗ): Ásbrú Connection Manager NextGen (MobaXterm Alternative on Go & GTK)

## 1. Введение и Назначение Проекта
Настоящее ТЗ определяет требования к созданию современного, высокопроизводительного и легковесного менеджера удаленных подключений и терминальных сессий уровня **MobaXterm / SecureCRT / Ásbrú** на языке **Go (Golang)** и **GTK / VTE**.

### 1.1. Проблематика устаревшей реализации (Ásbrú v6.x на Perl)
* **Технологический долг**: Устаревший и медленный стек Perl 5 + Gtk3-Perl + нестабильные биндинги LibVTE.
* **Критические баги ввода/вывода (I/O & Keybindings)**: Повторная отправка событий `key-press-event` через скриптовую прослойку Perl, приводящая к дублированию байтов (дублирование `0x18` при `Ctrl+X`, ломающее Safe Mode в MikroTik RouterOS и редактирование в Nano/Vim, некорректная обработка `F1-F12`).
* **Утечки памяти и тяжеловесность**: Высокое потребление ОЗУ (>150 МБ на 20 вкладок) и зависающие фоновые процессы `expect`.
* **Устаревание в дистрибутивах**: Сложности со сборкой в современных Linux из-за деградации экосистемы Perl GTK3.

## 2. Цели и Ключевые Метрики Проекта
1. **Качество уровня MobaXterm**: Полнофункциональный GUI-клиент с поддержкой SSH, SFTP, Telnet, Serial, VNC, RDP, Local Shell и продвинутым менеджментом сессий.
2. **Ликвидация багов ввода**: 100% нативная и чистая передача ANSI/ASCII байтов в PTY без дублирования (эквивалентно `mate-terminal` / `gnome-terminal`).
3. **Легковесность и нативность для MATE DE**:
   - Традиционный десктопный UX (MenuBar + ToolBar + Tabs + Sidebars + Statusbar).
   - Потребление RAM: 30–50 МБ при 20+ активных сессиях.
   - Мгновенный запуск: Time To Interactive (TTI) < 0.3 сек.
4. **Универсальное управление (Мышь + Клавиатура)**:
   - Все операции доступны как через горячие клавиши, так и через мышь (контекстные меню, кнопки тулбара, Drag-and-Drop, главное меню).
5. **Полная персистентность**:
   - Автосохранение логов сессий в `.txt`.
   - Восстановление открытых вкладок и полной истории терминалов при перезапуске программы.
   - Боковые заметки к каждой сессии с автосохранением.
6. **Обратная совместимость**:
   - Прозрачный импорт конфигураций Ásbrú v5/v6 (`asbru.conf` в форматах YAML и Perl `Data::Dumper`).

## 3. Архитектура и Стек Технологий

### 3.1. Технологический стек
* **Язык разработки**: Go 1.22+ (высокая скорость, нативная конкурентность горутин, минимальный футпринт).
* **Графический интерфейс**: Native GTK / CGO биндинги с классическим MATE-стилем.
* **Терминальный виджет**: `libvte` (нативный рендеринг, поддержка TrueColor 24-bit, 256 цветов, xterm-256color, URL matching).
* **SSH Engine**: `golang.org/x/crypto/ssh` (нативный Go-клиент, полный контроль PTY, сокетов и туннелей без системного `ssh`/`expect`).
* **SFTP Engine**: `github.com/pkg/sftp` (асинхронный файловый менеджер в отдельных горутинах).
* **Serial Engine**: `go.bug.st/serial` (нативный доступ к COM/TTY портам).
* **Хранилище данных**: SQLite (`modernc.org/sqlite` — чистый Go-драйвер без CGO) + кэш сессий в JSON.
* **Шифрование и Keyring**:
  - D-Bus Secret Service API (`github.com/godbus/dbus`) для интеграции с Gnome Keyring / KeePassXC.
  - Встроенный fallback: локальная зашифрованная база SQLite (AES-256-GCM + Argon2id).
* **File Watcher**: `github.com/fsnotify/fsnotify` для отслеживания изменений локально открытых удаленных файлов.

## 4. Подробные Функциональные Требования

### 4.1. Подсистема терминала и ввод/вывод (Terminal I/O)
1. **Прямой PTY-мост (Direct PTY Bridge)**:
   - Ввод с клавиатуры транслируется напрямую в PTY мастер-сокет без промежуточных скриптовых перехватчиков.
   - Исключено любое дублирование байтов (`Ctrl+X`, `Ctrl+C`, `Ctrl+Z`, `Ctrl+O`, `Ctrl+K`, `F1–F12`, эскейп-последовательностей).
   - Полноценная поддержка Safe Mode в MikroTik RouterOS v6/v7 и всех CLI-редакторов (Nano, Vim, Micro, MC).
2. **Управление мышью в терминале**:
   - Выделение текста, копирование по выделению (опционально), вставка по клику СКМ (колесиком) или ПКМ (контекстное меню).
   - Поддержка Xterm Mouse Tracking (клик и скролл мышью в `mc`, `htop`, `links`, `nano`).
   - Кликабельные URL-ссылки (Ctrl + клик или клик через контекстное меню) с открытием в системном браузере.

### 4.2. Управление вкладками и рабочим пространством (Tabs & Splits)
1. **Организация вкладок**:
   - **Перемещение (Reorder)**: Перетаскивание вкладок мышью (Drag-and-Drop) + горячие клавиши перемещения влево/вправо (`Ctrl+Shift+PageUp/PageDown`).
   - **Переименование (Rename)**: Двойной клик по вкладке, пункт в контекстном меню ПКМ «Переименовать вкладку» или шорткат `F2` — открывают инлайн-редактирование имени.
   - **Сплиты**: Разделение активного экрана по горизонтали и вертикали (2x2, 1x3 и т.д.) через меню, тулбар и горячие клавиши.
   - **Управление**: Кнопка закрытия `[x]` на каждой вкладке, контекстное меню: «Закрыть», «Закрыть остальные», «Дублировать сессию», «Переподключиться», «Свойства сессии».
2. **Поиск по сессиям**:
   - **Локальный поиск в текущей вкладке (`Ctrl+Shift+F`)**: Выезжающая панель поиска с подсветкой результатов, учетом регистра/regex, кнопками «Следующее/Предыдущее».
   - **Глобальный поиск по всем сессиям (`Ctrl+Shift+Alt+F`)**: Модальное окно или нижняя панель, выполняющая мгновенный поиск по буферам всех активных терминалов с выводом списка совпадений `[Имя хоста:Строка] -> Переход к вкладке по клику`.
3. **Кластерный ввод (Broadcast Input)**:
   - Специальная панель ввода (Broadcast Input Bar), позволяющая отправить введенную строку/команду во все открытые или выбранные сессии одновременно.
   - Возможность переключения режима «Зеркалирование клавиатуры» (Mirror mode) через тулбар.

### 4.3. Персистентность: Логи, Восстановление сессий и Заметки
1. **Автоматическое логирование в TXT (Session Logging)**:
   - В настройках хоста и глобальных настройках: флаг `[x] Вести лог сессии`.
   - Шаблон пути сохранения (например, `~/logs/sessions/{hostname}_%Y%m%d_%H%M%S.txt`).
   - Опция очистки от ANSI-последовательностей (чистый текст) или сохранение RAW-лога.
   - Индикатор записи лога в строке состояния (с возможностью открыть текущий лог-файл в 1 клик).
2. **Восстановление сессий и истории при перезапуске (Session & History Restore)**:
   - При штатном или аварийном закрытии программы состояние сессий сохраняется: список открытых хостов, структура сплитов, рабочие каталоги.
   - Сохраняется дамп последних $N$ строк терминального буфера.
   - При повторном запуске приложение восстанавливает вкладки, отрисовывает историю с разделителем вида:
     `--- [Восстановленная история сессии: 2026-08-23 01:30] ---`
     и выполняет авто-реконнект.
3. **Боковая панель заметок (Session Notes)**:
   - Справа от терминала располагается сворачиваемая панель быстрых заметок к хосту (`GtkTextView` / Markdown).
   - Кнопка на тулбаре и в меню для быстрого скрытия/показа (`F4` или `Ctrl+Alt+N`).
   - Заметки автоматически сохраняются в базу данных и подгружаются при каждом открытии сессии этого хоста.

### 4.4. Встроенный SFTP Файловый Менеджер (MobaXterm Style)
1. **Параллельная сессия и дерево файлов**:
   - Автоматический запуск SFTP-горутины параллельно с SSH-сессией без блокировки терминала.
   - Двухпанельный или древовидный вид каталогов в левой панели.
2. **Directory Tracking (Синхронизация директорий)**:
   - Перехват `OSC 7` / shell escape sequences для авто-перехода в SFTP при выполнении `cd /path` в терминале.
   - Кнопка на панели «Перейти в текущий каталог консоли» и адресная строка для ручного ввода пути.
3. **Drag-and-Drop и файловые операции**:
   - Drag-and-Drop файлов между SFTP-панелью и локальными файловыми менеджерами (Caja, Nemo, Nautilus, Dolphin).
   - Контекстное меню ПКМ: Скачать, Загрузить, Создать файл/папку, Переименовать, Удалить, Chmod, Chown, Свойства.
   - Менеджер фоновых передач с прогресс-баром и подсчетом скорости.
4. **Удаленное редактирование на лету (Remote Edit on the Fly)**:
   - Двойной клик по удаленному файлу $\to$ скачивание во временный каталог $\to$ открытие в системном текстовом редакторе (`xed`, `gedit`, `code`, `micro` и др.).
   - Движок `fsnotify` отслеживает сохранение файла в редакторе и автоматически загружает обновленный файл обратно на сервер по SFTP.

### 4.5. Поддерживаемые протоколы и сетевые функции
1. **SSH (Go Native)**:
   - Аутентификация: Пароль, Private Key (RSA, Ed25519, ECDSA, в т.ч. зашифрованные паролем), SSH-Agent (`SSH_AUTH_SOCK`), интерактивный Keyboard-Interactive.
   - **X11 Forwarding**: Обработка `x11-req`, проброс на локальный `$DISPLAY` с авторизацией через `XAUTHORITY`.
   - **Port Forwarding**:
     - Local Forwarding (`-L`): Локальный TCP-порт $\to$ удаленный хост.
     - Remote Forwarding (`-R`): Удаленный TCP-порт $\to$ локальный сервис.
     - Dynamic SOCKS5 Proxy (`-D`): Встроенный SOCKS5-сервер на Go.
   - **ProxyJump / Bastion Chains**: Каскадное туннелирование через промежуточные хосты нативно в Go.
2. **Local Shell**: Вкладка локального терминала (Bash/Zsh/Fish) через прямой Unix PTY.
3. **Telnet**: Нативный Go-клиент с поддержкой опций IAC (RFC 854/855).
4. **Serial / COM**: Подключение к консольным портам роутеров/коммутаторов с настройкой Baud rate (9600, 115200 и т.д.), Data bits, Stop bits, Parity, Flow control.
5. **VNC / RDP**: Встраиваемые сессии графических рабочих столов (через нативный RFB / GTK-VNC и FreeRDP X11 embed).

## 5. Пользовательский интерфейс (UI/UX) в стиле MATE

### 5.1. Структура окна
1. **Главное меню (MenuBar)**:
   - `Файл`: Новая сессия, Быстрое подключение, Менеджер туннелей, Импорт/Экспорт, Настройки, Выход.
   - `Правка`: Копировать, Вставить, Выделить всё, Найти в терминале, Глобальный поиск.
   - `Вид`: Показать/скрыть дерево хостов, SFTP-панель, Заметки, Тулбар, Статус-бар, Полноэкранный режим (F11).
   - `Сессии`: Дублировать, Переименовать, Переподключиться, Разделить экран (H/V), Запись лога.
   - `Инструменты`: Broadcast Input (Кластерный ввод), Генератор SSH-ключей, Проверка сети (Ping/Port scan).
   - `Справка`: Горячие клавиши, О программе.
2. **Панель быстрых кнопок (ToolBar)**:
   - Кнопки: [Новая сессия] [Быстрое подключение] | [Сплит V] [Сплит H] | [Кластерный ввод] | [SFTP] [Заметки] | [Поиск].
3. **Строка состояния (StatusBar)**:
   - Отображение: Статус подключения, Пинг/RTE, Индикатор записи лога (REC), Активные туннели, Кодировка (UTF-8).

| **AC-11** | **Миграция конфигураций**<br>Загрузка старого `asbru.conf` (Perl Data::Dumper / YAML). | 100% хостов, папок, логинов и настроек импортируются в новую базу. |
| **AC-12** | **Производительность и RAM**<br>Открытие 20+ активных SSH-вкладок. | Потребление RAM в пределах 30–50 МБ, мгновенная реакция GUI. |

## 7. Этапы Разработки (Roadmap)

1. **Этап 1: Core Engine & Clean I/O Bridge**
   - Настройка Go-модуля и связки GTK/VTE через CGO.
   - Реализация Unix PTY моста к `golang.org/x/crypto/ssh`.
   - Проверка отсутствия дублирования клавиш (`Ctrl+X`, `F1–F12`).
2. **Этап 2: Хранилище данных, Логирование, Заметки и Персистентность**
   - SQLite база данных (`modernc.org/sqlite`).
   - Модуль автосохранения логов в `.txt` (`io.MultiWriter`).
   - Модуль сохранения/восстановления состояния сессий и истории VTE.
   - Реализация боковой панели заметок к сессиям.
   - Парсер миграции `asbru.conf` (YAML + Perl Data::Dumper).
3. **Этап 3: Полнофункциональный UI в стиле MATE**
   - Главное окно: MenuBar, ToolBar, StatusBar, Host Tree (слева), Notes (справа).
   - Вкладки: Drag-and-Drop перемещение, инлайн-переименование, сплиты H/V.
   - Полнофункциональные контекстные меню (мышь + шорткаты).
   - Локальный поиск по терминалу и глобальный поиск по всем сессиям.
   - Broadcast Input панель.
4. **Этап 4: SFTP Файловый Менеджер & Сетевые протоколы**
   - Встроенная панель SFTP (`pkg/sftp`) с Drag-and-Drop.
   - Remote Edit watcher (`fsnotify`) с авто-загрузкой при сохранении в системном редакторе.
   - Directory tracking (OSC 7) + ручная синхронизация.
   - X11 Forwarding, Port Forwarding (-L, -R, -D) и ProxyJump.
   - Поддержка Local Shell, Telnet, Serial/COM, VNC/RDP.
5. **Этап 5: Сборка, QA и релиз на GitHub**
   - Подготовка репозитория, `Makefile`, Go-модулей и CI-сборки.
   - Тестирование под нагрузкой (RAM, CPU, стабильность туннелей).
