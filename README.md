# PAC Connection Manager NextGen (Go & GTK)

[![Go Version](https://img.shields.io/badge/Go-1.22+-00ADD8?style=flat&logo=go)](https://golang.org)
[![GTK Version](https://img.shields.io/badge/GTK-3.0%20%2F%20VTE-4B275F?style=flat&logo=gtk)](https://www.gtk.org/)
[![License](https://img.shields.io/badge/License-GPL%20v3-blue.svg)](LICENSE)

**PAC Connection Manager NextGen** — современный, сверхбыстрый и легковесный менеджер удаленных подключений и терминальных сессий уровня **MobaXterm** и **SecureCRT**, переписанный с нуля на языке **Go (Golang)** с использованием нативного **GTK+ / LibVTE**.

Проект является полной архитектурной модернизацией оригинального Ásbrú Connection Manager / PAC Manager, решающей проблемы технологического долга Perl, дублирования клавиатурных последовательностей (`Ctrl+X`, `F1-F12`), утечек памяти и предлагающей богатый набор новых возможностей.

---

## 🚀 Ключевые возможности и Преимущества

- **Ликвидация багов ввода/вывода (Clean Terminal I/O)**: 
  - Прямой Unix PTY-мост между нативным `golang.org/x/crypto/ssh` и `libvte`.
  - 100% корректная обработка клавиш: безупречная работа **Safe Mode в MikroTik RouterOS** (по нажатию `Ctrl+X`), отсутствие фантомных дублей в `nano`, `vim`, `micro`, `mc`.
- **Встроенный SFTP Файловый Менеджер (MobaXterm Style)**:
  - Автоматический запуск параллельной SFTP-сессии при SSH-подключении.
  - **Directory Tracking (OSC 7)**: автоматическая смена каталога в SFTP при выполнении `cd` в консоли.
  - **Remote Edit on the Fly**: открытие удаленных файлов в системном редакторе (`xed`, `gedit`, `code`) с автоматической выгрузкой на сервер через `fsnotify` при сохранении (`Ctrl+S`).
- **Управление вкладками и сплитами**:
  - Drag-and-Drop перетаскивание вкладок (Reorderable tabs).
  - Инлайн-переименование вкладок (двойной клик / `F2` / ПКМ).
  - Разделение рабочей области по горизонтали и вертикали (Splits H/V).
- **Полнотекстовый поиск**:
  - Локальный поиск в активном терминале (`Ctrl+Shift+F`) с регулярными выражениями и подсветкой.
  - **Глобальный поиск по всем сессиям одновременно** (`Ctrl+Shift+Alt+F`) с быстрым переходом к найденной строке.
- **Кластерный ввод (Broadcast Input Bar)**:
  - Отправка введенных команд одновременно во все открытые или выбранные сессии.
- **Персистентность и восстановление**:
  - **Session Logging**: автоматическая запись вывода терминалов в текстовые `.txt` файлы (с очисткой от ANSI или в RAW-формате).
  - **Восстановление сессий и истории**: автоматическое сохранение открытых вкладок и последних строк терминального буфера при выходе с восстановлением при следующем запуске.
  - **Боковая панель заметок**: ведение персональных заметок к каждому хосту с сохранением в SQLite базе данных.
- **Протоколы**:
  - **SSH**: нативный клиент с поддержкой X11 Forwarding (`-X`), Port Forwarding (`-L`, `-R`, `-D` SOCKS5 proxy), ProxyJump / Bastion chains, SSH Agent (`SSH_AUTH_SOCK`), приватных ключей и паролей.
  - **Local Shell**: локальный терминал (Bash/Zsh/Fish).
  - **Telnet**: нативный RFC 854/855 клиент с IAC-переговорами.
  - **Serial / COM**: прямое подключение к COM-портам через `go.bug.st/serial`.
- **Обратная совместимость**:
  - Автоматический импорт конфигураций Ásbrú v5/v6 (`asbru.conf` / `pac.yml` / Perl `Data::Dumper`).

## 🛠 Системные требования и Сборка

### Зависимости (Debian / Ubuntu / MATE)
```bash
sudo apt install -y golang build-essential pkg-config libgtk-3-dev libvte-2.91-dev libpcre2-dev
```

### Сборка из исходников
```bash
git clone https://github.com/darakcheeff/pac.git
cd pac
make
```

### Запуск
```bash
./pac
```

### Установка в систему
```bash
sudo make install
```

## ⌨️ Горячие клавиши

| Сочетание клавиш | Действие |
|---|---|
| `Ctrl+Shift+F` | Найти в текущем терминале |
| `Ctrl+Shift+Alt+F` | Глобальный поиск по всем сессиям |
| `F2` | Переименовать активную вкладку |
| `Ctrl+Shift+T` | Новое быстрое подключение |
| `Ctrl+Shift+W` | Закрыть текущую вкладку |
| `Ctrl+Shift+C` | Копировать выделенный текст |
| `Ctrl+Shift+V` | Вставить из буфера обмена |
| `F11` | Полноэкранный режим |
